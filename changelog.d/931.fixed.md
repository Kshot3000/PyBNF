- **A fit whose free parameters differ only in capitalisation (such as `k` and `K`) is now
  refused when the configuration loads (#931).** Each parameter's histogram is written to
  `Results/Histograms/<name>_final.txt` (and profile likelihood writes `profile_<name>.txt`),
  and on the case-insensitive file systems that are the default on macOS and Windows those
  names are the same file, so one parameter's file silently replaced the other's. Declaring
  the same parameter name twice is refused on the same grounds. Rename one of the parameters
  so that no two free parameter names differ only in capitalisation.
